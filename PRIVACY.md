# Privacy Policy — AWS Inventory Power

**Last updated**: August 2026

## Data Collection

This Kiro Power does **not** collect, transmit, or store any personal data or AWS account information.

## How It Works

- All AWS API calls are made **directly from your local machine** using your own AWS credentials.
- Inventory data (resource metadata, tags, configuration) is written to a local Excel file in your workspace. No data leaves your machine.
- No telemetry, analytics, or tracking of any kind is included in this power.

## MCP Servers

This power uses the following MCP servers:

| Server | Privacy |
|---|---|
| [aws-mcp](https://docs.aws.amazon.com/aws-mcp/latest/userguide/) | AWS managed. API calls go directly to AWS using your credentials. See [AWS Privacy Policy](https://aws.amazon.com/privacy/). |
| [aws-documentation-mcp-server](https://github.com/awslabs/mcp) | Fetches public AWS documentation. No user data transmitted. See [AWS Privacy Policy](https://aws.amazon.com/privacy/). |

## Third-Party Services

This power does not integrate with any third-party services beyond the AWS APIs accessed through your own credentials.
